# Evaluating Dermatology Image Generation Across Skin Tones

This repository accompanies the paper:

**Examining Dermatology Image Generation Capabilities of Generative AI Across Skin Tones**

## Overview

This repository contains the evaluation pipeline used to assess dermatology images generated by large multimodal models. In our study, we used this specifically for ChatGPT 5.5 Instant and Gemini 3.5 Flash.

The framework evaluates:

- Monk Skin Tone fidelity
- Diagnostic accuracy using BioMedCLIP
- Diagnostic consistency
- Statistical analyses

---

## Repository Contents

### evaluate_mst.py

Evaluates Monk Skin Tone fidelity using the official Monk Skin Tone reference colors and the CIE76 ΔE color difference metric.

Outputs:

- Exact accuracy
- Mean Absolute Error (MAE)
- Calibration

---

### run_biomedclip.py

Evaluates diagnostic fidelity using publicy available BioMedCLIP. BioMedCLIP is developed by Microsoft research, pretrained on the PMC-15M dataset.

---

### analyze_results.py

Calculates diagnostic accuracy grouped by disease, prompt, image generator, and Monk Skin Tone.

---

### consistency_analysis.py

Measures diagnostic consistency across requested Monk Skin Tone categories.

---

### utils/image_features.py

Contains helper functions for skin segmentation and representative skin color extraction.
